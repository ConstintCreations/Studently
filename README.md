# Studently
Studently is a customizable student dashboard web app. It helps students stay organized, track events, and more!

## How it Works:

1. The Studently Dashboard is made up of modules, housed in a station. To edit the dashboard, click the icon in the top left. This will take you to your stations.
2. From there, you can add or edit stations and set 1 main and multiple secondary modules.
3. Save your changes with the Add Station or Edit Station button and watch them take effect!

## Modules

Studently has the following modules:

- **Bell Schedule** - View the current day's schedule.
- **Bell Timer** - See the time until the next bell.
- **To-Do List** - Track tasks that need to get done.
- **Upcoming Events** - View all events sorted by date.
- **Weather** - Current weather with an icon, current temperature, and daily low and high.

## Customization

In the settings menu (icon in the top right), you can customize your:

- Theme
- Bell Schedules
- Events
- Weather Location

This allows you to personailze the site to your personal preferences or your school's schedules.

## Data
All data is saved in the browser via local storage. No data is collected.
